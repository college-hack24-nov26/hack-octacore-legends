11 Mathematical Directionality Metrics STRICT EXCLUSION GATE
1. Packet Asymmetry (Ap)
(FwdPkts - RevPkts) / TotalPkts
2. Byte Asymmetry (Ab)
(FwdBytes - RevBytes) / TotalBytes
3. Directional Ratio (R)
FwdPkts / (RevPkts + ε)
4. Reverse Presence Indicator
1 if RevPkts > 0 else 0
5. SYN-ACK Latency Delta
Time between SYN and SYN-ACK
6. TCP State Completeness
Valid 3-way handshake ratio
7. Data/ACK Ratio
Data carrying packets vs pure ACKs
8. Inter-Arrival Variance
Fwd vs Reverse IAT variance ratio
9. Push-Flag Concentration
Fwd PSH packets / Total PSH
10. Reverse Window Size
Mean advertised receive window
